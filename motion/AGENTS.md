# سرب وكلاء Motion (Swarm Rebuild)

أربعة وكلاء في Claude Code، وكل واحد له دور واحد واضح. تعريفاتهم في `.claude/agents/`.

| الوكيل | الدور | يكتب في |
|---|---|---|
| ✍️ `motion-writer` | **الكتابة**: خطوات الكود ونوع نتيجة كل خطوة | `specs/<name>.py` ← `BLOCKS` و`META` |
| 💬 `motion-explainer` | **الشرح**: سهم لكل عنصر وشرائط الخطوات | `specs/<name>.py` ← `NOTES` و`CAPTIONS` و`ER_NOTES` و`PANEL_NOTES` |
| 🎨 `motion-designer` | **التصميم**: الهوية والرسومات والتأثيرات | `META['theme']`، `sql_reel.py`، `code_typer.py` |
| 🎬 `motion-presenter` | **العرض**: التجميع والموسيقى والإخراج والمراجعة | `<name>_reel.mp4` |

## مسار العمل
```
            ┌──────────────┐
  الموضوع → │ ✍️ الكتابة   │  BLOCKS (كود قابل للتنفيذ)
            └──────┬───────┘
          ┌────────┴────────┐
   ┌──────▼──────┐   ┌──────▼──────┐
   │ 💬 الشرح    │   │ 🎨 التصميم  │   ← يشتغلون بالتوازي
   └──────┬──────┘   └──────┬──────┘
          └────────┬────────┘
            ┌──────▼───────┐
            │ 🎬 العرض     │  sql_reel.py ← lofi.py ← code_typer.py ← مراجعة
            └──────────────┘
```

## كيف تطلبه في Claude Code
اكتب مثلاً:
> «شغّل سرب Motion: ريل SQL عن مكتبة (كتب، مؤلفين، استعارات). الكتابة بعدها الشرح والتصميم بالتوازي بعدها العرض.»

أو نادِ وكيل واحد بالاسم:
> «خلّ motion-explainer يضيف شرح لكل عنصر في specs/sql_company.py»

## المحرّكات (مشتركة بين الوكلاء)
- `sql_reel.py --spec <name>`: ينفّذ الـ SQL فعلياً، ويرسم النتائج والمخطط والختام، ويكتب ملف الـ JSON.
- `code_typer.py`: المونتاج. فيه الكتابة، والتبويبات، ولوحات النتائج، وتأثير Swarm Rebuild، والأسهم، والسبوت لايت، والزوم، والشرائط، وصوت الكيبورد.
- `lofi.py --style energetic|lofi`: موسيقى أصلية بدون حقوق.
