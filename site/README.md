# موقع FAHAD MOHAMMED

موقع شخصي بهوية «الختم» (أخضر `#123A31` · ذهبي `#C8A45D` · كريمي `#F3EEE4`)
مع نموذج تواصل يحفظ الرسائل في قاعدة بيانات SQL.

## الملفات
| الملف | اللغة | وظيفته |
|---|---|---|
| `index.html` | HTML | هيكل الصفحة: الشريط، الواجهة، نبذة، أعمالي، نموذج التواصل |
| `style.css` | CSS | الألوان والخطوط والتنسيق والحركة |
| `app.js` | JavaScript (المتصفح) | حركة ظهور الأقسام + إرسال النموذج للخادم |
| `server.js` | JavaScript (Node.js) | الخادم: يعرض الصفحة ويستقبل الرسائل ويحفظها في القاعدة |
| `schema.sql` | SQL | تعريف جدول `messages` |
| `assets/` | صور | الختم بثلاثة ألوان |

## كيف ارتبطت قاعدة البيانات SQL بالموقع؟

```
المتصفح                    الخادم (server.js)               قاعدة البيانات (site.db)
───────                    ──────────────────               ───────────────────────
index.html  ← يعرض الصفحة ← GET /
الزائر يعبّي النموذج
app.js: fetch() ──JSON──→ POST /api/messages
                           يتحقق من البيانات
                           insert.run(...) ──SQL──→  INSERT INTO messages ...
                           ←── { ok: true } ──
"وصلت رسالتك ✓"
```

1. **`schema.sql`**: ينشئ جدول `messages` (id، name، email، message، created_at).
2. **`server.js`** عند التشغيل: يفتح ملف `site.db` عبر `node:sqlite`، وينفّذ `schema.sql`،
   ويجهّز استعلام `INSERT` باستخدام علامات `?`. هذي العلامات تحمي من حقن SQL.
3. **`app.js`** في المتصفح: لما يضغط الزائر «أرسل» يرسل البيانات بـ `fetch` إلى `/api/messages`.
4. الخادم يتحقق من الحقول، ثم يحفظها بـ `INSERT INTO messages ...` ويرد بنجاح.
5. أنت تقرأ الرسائل من `/api/messages?token=رمزك` (وهذا يحتاج متغير البيئة `ADMIN_TOKEN`).

> المتصفح ما يكلّم قاعدة البيانات مباشرة أبداً. الخادم هو الوسيط، وهذا اللي يحمي بياناتك.

## التشغيل
يحتاج Node.js 22.13 أو أحدث، وما يحتاج تثبيت أي حزم:
```bash
cd site
ADMIN_TOKEN=اختر-رمز-سري node server.js
# افتح http://localhost:3000
```
قراءة الرسائل: `http://localhost:3000/api/messages?token=اختر-رمز-سري`

## للتعديل
- النصوص (النبذة، الأعمال، الشعار الفرعي) في `index.html`.
- الألوان في أعلى `style.css` (`:root`).
- للنشر الفعلي تحتاج استضافة تشغّل Node.js، مثل Render أو Railway أو VPS.
  لو تبي قاعدة أكبر من SQLite، تقدر تبدّلها بـ PostgreSQL بنفس الفكرة.
